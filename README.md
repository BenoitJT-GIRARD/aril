# aril

Placeholder for the `w3id.org/aril` namespace.

Identifiers under that namespace name the parts of a metadata vocabulary for animal behaviour
data. They are frozen once minted, so the address has to keep resolving long after any particular
hosting arrangement has been replaced — which is what the w3id redirect is for.

Nothing is published here yet. This repository serves one page so the namespace resolves in the
meantime.
